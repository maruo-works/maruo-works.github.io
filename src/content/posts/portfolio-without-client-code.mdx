## 仕事のコードは、出せない

業務委託で作ったコードは、たいてい取引先のものです。システム名や金額の決まりも入っています。そのまま公開すれば、信用を失います。

でも GitHub に何もないと、「成果物がない人」に見えます。

## 出せるのは、身につけた技術

同じ技術で、架空のデータを使い、小さなツールを作り直しました。

| 仕事で作ったもの | 作り直して公開したもの |
|---|---|
| 新着情報から、サイトの下書きを作る仕組み | [feed2wp-draft](https://github.com/maruo-works/feed2wp-draft) |
| 月次の Excel を、書式を崩さず次の月へ進めるツール | [xlsx-month-roll](https://github.com/maruo-works/xlsx-month-roll) |

## 作り直すときの3つ

<Steps>
1. **取引先の名前や仕組みを持ち込まない**
   RSS・WordPress・Excel など、どこにでもある形だけで作る。
2. **何もなくても試せるようにする**
   見本のデータを入れ、1行のコマンドで動きを確かめられるようにする。
3. **説明とテストを付ける**
   公開前に、コミットの名前とメールに本名が出ていないことも確かめる。
</Steps>

仕事のコードは見せられなくても、考え方と技術は見せられます。
