## 3つだけ

<Cards>
  <Card title="GitHub ＝ 家">
    サイトのファイルを置く場所。置いたまま、無料で公開される。公開設定のものは、誰でも読める。
  </Card>
  <Card title="ドメイン ＝ 住所">
    maruo-works.com のような名前。年に1回、更新する。
  </Card>
  <Card title="DNS ＝ 住所録">
    「この住所の家はここ」と書く表。ドメインを買った所で書く。
  </Card>
</Cards>

ドメインを買っただけでは、住所があって家がない状態です。住所録に家の場所を書くと、つながります。

## 流れ

<Steps>
1. **ドメインを買う**
   Cloudflare で名前を探して買う。自動更新はオン。
2. **GitHub に登録する**
   Pages の設定でドメインを足すと、確認用の文字列が出る。持ち主を示すためのもの。
3. **住所録に書く**
   確認用の1行と、家の場所の9行。9行は、GitHub の入口4か所を A と AAAA で4行ずつ、残り1行は www 用。値は GitHub の案内どおり。
4. **確かめる**
   Verify を押し、Custom domain に入れて、「DNS check successful」が出れば成功。
5. **鍵（HTTPS）を待つ**
   GitHub が証明書を出したら、「Enforce HTTPS」をオン。
6. **サイトの設定を変える**
   Astro なら site の1か所。古いアドレスは、自動で新しいほうへ転送される。
</Steps>

<Sample label="DNS に入れた9行" note="確認用の1行は人ごとに違うので載せていません。">

| 種類 | 名前 | 中身 | 意味 |
|---|---|---|---|
| A（4行） | @ | 185.199.108.153 〜 111.153 | 家の場所 |
| AAAA（4行） | @ | 2606:50c0:8000::153 〜 8003::153 | 家の場所（新しい形式） |
| CNAME | www | maruo-works.github.io | www でも同じ家へ |

</Sample>

「@」は、ドメインそのもの（maruo-works.com）です。

## つまずきやすいところ

<Cards>
  <Card title="オレンジの雲は、灰色に">
    Cloudflare のプロキシ（見に来た人とサイトのあいだで通信を中継するしくみ）はオフにする。オンだと GitHub が鍵を出せない。
  </Card>
  <Card title="確認メールは15日以内に">
    届くリンクを押さないと、ドメインが止まることがある。
  </Card>
  <Card title="待つ時間がある">
    最大24時間と書かれていたが、今回は数分〜十数分だった。
  </Card>
</Cards>

やることは、住所録に書いて、GitHub に住所を教えること。それだけです。共に頑張りましょう。
