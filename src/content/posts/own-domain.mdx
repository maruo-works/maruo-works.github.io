## 登場するのは3つだけ

<Cards>
  <Card title="GitHub ＝ 家">
    サイトのファイルを置く場所。変更のたびに記録が残り、置いたものをそのまま公開してくれる。
  </Card>
  <Card title="ドメイン ＝ 住所">
    maruo-works.com のような、サイトの名前。Cloudflare などで買い、年に1回更新する。
  </Card>
  <Card title="DNS ＝ 住所録">
    「この住所の家はここ」と書いておく表。ドメインを買ったところで書く。
  </Card>
</Cards>

ドメインを買っただけでは、住所はあるのに家が決まっていない状態です。住所録に家の場所を書いて、はじめてつながります。

## なぜ GitHub に置くのか

<Cards>
  <Card title="サーバー代がかからない">
    GitHub Pages という機能で、無料で公開できる。かかるのはドメイン代だけ。
  </Card>
  <Card title="送ると、すぐ公開">
    変更を GitHub に送ると、1分ほどでサイトに反映される。
  </Card>
  <Card title="記録が残り、戻せる">
    いつ・何を変えたかが1件ずつ残る。壊しても前の状態に戻せる。
  </Card>
  <Card title="作り方が見本になる">
    エンジニアや依頼主は、GitHub を見て「どう作る人か」を確かめることがある。
  </Card>
</Cards>

ひとつだけ注意があります。公開の設定にしていると、送ったものは誰でも読めます。下書きや個人の情報は送らないようにします。

## つなぐまでの流れ

<Steps>
1. **ドメインを買う**
   Cloudflare で名前を検索し、空いていれば買う。連絡先はローマ字で入れる（外からは隠される）。自動更新はオンのまま。
2. **GitHub に「自分のドメイン」と登録する**
   GitHub の設定（Pages）でドメインを足すと、確認用の名前と文字列が出る。ほかの人に勝手に使われないための手続き。
3. **住所録（DNS）に書く**
   確認用の1行と、家の場所の9行。Cloudflare は、ファイルからまとめて取り込める。
4. **GitHub で確かめて、ドメインを設定する**
   「Verify」を押す。サイトの設定の Custom domain に入れて、「DNS check successful」と出れば成功。
5. **鍵（HTTPS）を待つ**
   GitHub が鍵（証明書）を発行するまで待ち、「Enforce HTTPS」をオンにする。
6. **サイトの設定を新しい住所に変える**
   Astro なら site の1か所だけ。古いアドレスは、新しいほうへ自動で転送される。
</Steps>

## 住所録に書いたもの

<Sample label="DNS に入れた9行" note="GitHub Pages の案内どおりの値です。確認用の1行は人ごとに違うので載せていません。">

| 種類 | 名前 | 中身 | 意味 |
|---|---|---|---|
| A（4行） | @ | 185.199.108.153 〜 111.153 | 家の場所 |
| AAAA（4行） | @ | 2606:50c0:8000::153 〜 8003::153 | 家の場所（新しい形式） |
| CNAME | www | maruo-works.github.io | www をつけても同じ家へ |

</Sample>

「@」は、ドメインそのもの（maruo-works.com）という意味です。

## つまずきやすいところ

<Cards>
  <Card title="オレンジの雲は、灰色に">
    Cloudflare は「プロキシ」をすすめてくるが、オンだと GitHub が鍵を発行できない。黄色い案内は気にしなくていい。
  </Card>
  <Card title="確認メールは15日以内に">
    買うと、持ち主の確認メールが届く。リンクを押さないと、ドメインが止まることがある。
  </Card>
  <Card title="アカウントはそろえる">
    ドメインやフォームは、活動用のアカウントで作る。学校のアドレスだと、卒業後に受け取れなくなる。
  </Card>
  <Card title="待つ時間がある">
    住所録の反映や鍵の発行には時間がかかる。最大24時間と書かれているが、今回はどちらも数分〜十数分だった。
  </Card>
</Cards>

分からない言葉が多くても、やることは「住所録に書いて、GitHub に住所を教える」だけです。役割が分かれば、画面の言葉も読めるようになります。
